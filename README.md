## Business question

Are returns concentrated in particular payment and city-tier segments, and do bulk-order outliers distort the monthly revenue story? This repository builds three connected layers: a raw relational reporting layer in SQLite, an independent cleaning and EDA pipeline in pandas, and a findings-grounded Situation–Complication–Resolution (SCR) narrative.

The supplied CSVs are the source of truth and are never edited by the analysis. SQL reports use the raw 180 order rows. Pandas independently cleans those same source files, then writes the computed figures to `narrator/findings.json`. The narrator reads that JSON; it does not calculate or invent business metrics.

## Run the pipeline in this order

Run commands from the repository root. The layers are deliberately ordered so the source data, computed results, and narrative stay traceable.

### 1. Build and report from the raw SQLite tables

Install the [SQLite command-line shell](https://sqlite.org/download.html), then create a fresh database and run the schema, seed inserts, and reports in order:

```powershell
sqlite3 mamaearth.db ".read sql/schema.sql"
sqlite3 mamaearth.db ".read sql/seed_data.sql"
sqlite3 mamaearth.db ".read sql/reports.sql"
```

`schema.sql` creates the three tables and enables foreign keys. `seed_data.sql` loads all CSV rows as SQL values, preserves blank discount/rating cells as `NULL`, and clears existing rows first so it can be re-run. `reports.sql` reports the raw totals, rating nulls, zero-order customer, city returns, customer rankings, category revenue, acquisition sources, and loyalty tiers. Run the report file once per freshly created schema because its final task adds `loyalty_tier` with `ALTER TABLE`.

Expected raw SQL anchors: 45 customers, 16 products, 180 orders; raw order revenue INR 99,860.20 and average order value INR 554.78; 15 missing ratings; customer C045 has no order; the highest-return city is Jaipur at 42.1%.

### 2. Clean and analyze the CSVs with pandas, then make charts

Create a Python environment and install the project dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run the independent pandas pipeline, then the visualization script:

```powershell
python analysis/clean_and_eda.py
python analysis/visualize.py
```

The first command prints each requested intermediate check, standardizes payment methods, removes the five natural-key duplicates, fills missing values, reconciles revenue, flags quantity outliers without deleting them, calculates segment/correlation/time-series summaries, and writes the local `analysis/eda_results.json` intermediate. At the end, it writes the verified computed figures to `narrator/findings.json` (Part 3 Task 1). The second command reads that intermediate artifact and regenerates both PNGs from the same results.

[`analysis/mamaearth_returns_walkthrough.ipynb`](analysis/mamaearth_returns_walkthrough.ipynb) is the Google Colab walkthrough. Open it with the badge above. It can clone this public repository when launched directly in Colab, then runs the SQL schema/seed/reports first, calls the same required `clean_and_eda.py` pipeline, regenerates both charts, and demonstrates the offline narrative checker. It does not replace or duplicate the required SQL and Python source files.

Expected pandas anchors: cleaned revenue INR 97,358.30; duplicate reconciliation delta INR 2,501.90; COD return rate 44.4%; COD + Tier-2 return rate 54.5%; the only quantity outliers are O0011 and O0098. Including those outliers makes January appear to lead at INR 29,582.10; after excluding them, March is the actual peak at INR 20,318.90.

### 3. Write the SCR narrative from the computed findings

The repository uses Google's `google-genai` client. [Google AI Studio](https://aistudio.google.com/app/apikey) provides an API key with a free usage tier; use that free-tier key, never a paid-only key. The key is optional. To request an online narrative, set it in the environment for the current PowerShell session; do not put the key in a source file:

```powershell
$env:GEMINI_API_KEY = "YOUR_FREE_AI_STUDIO_KEY"
python narrator/generate_narrative.py
```

In Google Colab, store the key in **Secrets** instead of typing it into a cell: click the key icon in the left sidebar, add a secret named `GEMINI_API_KEY`, paste the key into its value, and enable notebook access. The walkthrough reads that secret with `google.colab.userdata` and passes it to the same narrator script. Never commit the secret to GitHub.

`GEMINI_MODEL` can optionally select another available model; the default is `gemini-2.5-flash` so the request can honor the brief's required `temperature=0.0`. The request sets a 500-token output limit and a 60-second timeout, and gives the verified JSON to the model as the prompt input. The script checks the saved `narrator/sample_output.txt` for every required number. If the selected model is unavailable to the account, the error is caught and the offline fallback still runs.

To run with no key, no network, and no API spend, leave `GEMINI_API_KEY` unset and run the same command:

```powershell
Remove-Item Env:GEMINI_API_KEY -ErrorAction SilentlyContinue
python narrator/generate_narrative.py
```

The deterministic offline template reads the same `findings.json`, prints the same numeric accuracy checklist, and replaces `narrator/sample_output.txt` with its SCR narrative. If the API call fails, the script automatically takes this offline path.

## Reconciliation and interpretation

The SQL layer's INR 99,860.20 is the raw-source revenue. The pandas layer's INR 97,358.30 is lower by INR 2,501.90 because it removes five repeated orders; the dropped rows' own order values sum to that exact delta. Missing-discount imputation uses 0% and does not alter the revenue. Missing ratings are filled with the deduplicated median of 3.0.

COD return risk is concentrated: COD is 44.4% overall and 54.5% for Tier-2 orders (versus 37.5% for Tier-1 COD). All six correlations among rating, return status, discount, and quantity are negligible; the discount/return correlation is approximately -0.09. These are descriptive associations, not evidence of causation. The files contain revenue inputs but no cost or margin data, so this pipeline quantifies revenue and returns rather than contribution margin.
